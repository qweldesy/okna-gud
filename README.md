# Окна-Гуд — сайт с 3D-конфигуратором

Редизайн сайта **окна-гуд.рф**: тёмный glassmorphism, крупная типографика, bento-сетка,
реальные фото объектов и интерактивный 3D-конфигуратор с мгновенным расчётом стоимости.

## Быстрый запуск

Проект статический, сборка не нужна. Запустите локальный сервер из папки проекта:

```bash
cd okna-gud
python3 -m http.server 4173
```

Откройте <http://127.0.0.1:4173/>.

> Важно: для ES-модулей (Three.js) и import map нужен HTTP-сервер. Двойной клик по `index.html`
> не подойдёт — браузер заблокирует импорт модулей по `file://`.

### Секции

1. **Hero — видео, проигрываемое скроллом** (`js/hero-zoom.js`, ролик `video/hero-flight.mp4`):
   наезд на чёрный хай-тек дом → стеклянная стена распахивается гармошкой →
   появляется название компании. Скролл управляет `currentTime` видео
   (нужен сервер с поддержкой Range — см. `dev-server.py`).
   Фолбэк при `prefers-reduced-motion` — статичный постер + название.
2. «Почему мы» — bento-сетка: энергоэффективность, акустика, безопасность, монтаж,
   гарантия и отдельная карточка собственного производства.
3. **3D-конфигуратор** — тип, размеры, профиль, стеклопакет, цвет, опции и живая цена.
4. **Проекты** — аккордеон-галерея из 5 реальных объектов (React Bits AccordionGallery,
   vanilla-порт на GSAP, `js/accordion-gallery.js`): свёрнутые панели ч/б, активная —
   цветная с подписью; клик по активной открывает её конфигурацию в 3D.
5. Процесс, реальные отзывы с Яндекс Карт, FAQ, форма замера, футер с гигантским логотипом.

## 3D-конфигуратор

- Полностью локальный Three.js, без внешних ассетов и CDN.
- Ленивая загрузка: Three.js (≈1,3 МБ) скачивается только при приближении к секции.
- Модель собирается процедурно: рама, створки, стекло, фурнитура, откосы, подоконник, москитная сетка.
- Ширина и высота — чипы **ScrubField** (React Bits, vanilla-порт в `js/scrub-field.js`):
  потяните чип, чтобы «скрабить» размер, клик — ввод с клавиатуры, Shift — шаг ×10,
  Alt — шаг ×0.1, у границ работает резиновый возврат. Цена пересчитывается на каждый шаг.
- Реагирует на 11 параметров: тип конструкции, размеры, профиль, стеклопакет, цвет, 5 опций,
  положение створки.
- Створка открывается анимацией, сцена вращается мышью/пальцем и масштабируется колесом;
  есть кнопки поворота, сброса и открывания для клавиатуры.
- При отсутствии WebGL показывается текстовый fallback, а расчёт цены продолжает работать.
- `prefers-reduced-motion` отключает декоративные анимации.

### Формула цены

Базовая цена считается в `js/main.js`:

```
площадь = (ширина / 1000) × (высота / 1000)
окно = площадь × (ставка профиля × коэффициент типа + добавка стеклопакета + добавка цвета)
итого = окно + опции + монтаж
```

Ставки и цены опций лежат в `data-` атрибутах полей в `index.html` — их удобно менять без правки JS.
Расчёт предварительный; итоговая сумма фиксируется после замера.

Конфигурация сохраняется в `localStorage` (`okna-gud-config-v1`), чтобы не терять выбор при обновлении.

## Формы

В `js/main.js` есть константа:

```js
const LEAD_ENDPOINT = "";
```

- Если указать URL (Formspree, Getform, свой API), формы отправляют туда JSON:
  `{ name, phone, comment, consent, source, config, page, createdAt }`.
- **Пока `LEAD_ENDPOINT` пустой, форма работает в демо-режиме**: показывает успешный экран,
  но заявка никуда не отправляется. Для боевого сайта обязательно подключите endpoint.
- Валидация: имя, телефон (10–11 цифр), обязательное согласие. Ошибки показываются под полями
  и связываются с input через `aria-describedby`.

## Деплой

Подойдёт любой статический хостинг: nginx/Apache, GitHub Pages, Netlify, Vercel, Cloudflare Pages.
Загружайте папку целиком, сохраняя структуру. Никаких переменных окружения и сборки не требуется.

Рекомендуется включить:
- HTTPS;
- кэширование статики (`fonts`, `img`, `vendor`) на 30 дней;
- gzip/brotli для CSS/JS (Three.js хорошо сжимается).

## Проверка качества

- Lighthouse: **Accessibility 100, Best Practices 100, SEO 100**, ошибок в консоли нет.
- Проверены ширины 390, 768, 1024, 1440 px.
- Клавиатурная навигация: табы конфигуратора, FAQ, формы, мобильное меню, диалоги; Esc закрывает
  меню и диалоги; фокус возвращается на кнопку.
- Для декоративных иконок используется `aria-hidden`, для рейтинга — `role="img"` + подпись.
- Учтён `prefers-reduced-motion`.

## Использованные технологии

- **Three.js** (MIT) — 3D-сцена, PBR-материалы, мягкие тени, окружение.
- **Motion for React (vanilla)** (MIT) — появление секций и hero, stagger, float-анимация искры.
- **Inter Tight / Inter** (SIL Open Font License) — локальные woff2, без Google Fonts в рантайме.
- Дизайн-система: тёмный glassmorphism по референсу; токены цвета/радиусов/отступов в `:root`.
- Правила из **ui-ux-pro-max** применены: контраст, focus-visible, тач-таргеты, 4/8-шкала,
  reduced-motion, адаптив; шрифтовая пара и стиль проверены через скилл.
